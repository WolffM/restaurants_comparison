## Trivia

- **Done in about 7 minutes.** Every commit this repo has ever had — the
  script, its README, and the README's rewrite — landed in just over 7
  minutes of each other on the same Saturday (`c01cb9e`, `6b1b689`).
- **The output shipped with the code.** The first commit included a
  pre-generated sample image, `restaurants_comparison.png`, committed right
  alongside the script that makes it (`c01cb9e`).
- **A README that outgrew itself fast.** Under five minutes after a
  26-line README was created, it was rewritten to add 98 lines and cut 13,
  more than quadrupling in size (`e3c7e5a`, `6b1b689`).
- **One fixed point, no setting.** Every distance the script reports is
  measured from a single pair of coordinates hardcoded directly in the
  script, with no way to change it short of editing the code (`c01cb9e`).
